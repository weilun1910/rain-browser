# Running - half marathon base

Building a base this fall for a half in April. Not chasing a time yet. Just consistent weeks.

## The week
- Tue: fartlek, 5 miles with 6 to 8 surges by feel
- Thu: easy 4
- Sat: easy 3 or rest
- Sun: long run, slow, add a mile every other week

Weekly target: 18 to 25 miles.

## Long run rules
- Conversation pace. If I can't talk, slow down.
- Negative split the last 2 miles if I feel good, never before.
- East Rock loop for hills, the Farmington Canal trail when I want flat
