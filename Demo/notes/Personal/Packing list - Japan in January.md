# Packing list - Japan in January

Tokyo in January is dry and cold. Highs around 10 C, near freezing at night. Kyoto feels colder. Hakone up in the mountains is colder still.

## Clothes
- Warm coat that packs small
- 2 sweaters, layers underneath
- Thermal base layer for Hakone
- Shoes that come off easily. Temples, ryokan, some restaurants.
- Socks without holes, for the same reason
- Hat, gloves

## Tech
- Phone with Suica added to Wallet
- eSIM bought before leaving
- Power bank. Japanese outlets are type A, same as the US, so no adapter needed.
- Noise cancelling headphones for the flight

## Documents
- Passport, valid for the whole trip
- Hotel and ryokan confirmations offline
- Visit Japan Web QR code for customs

## Small stuff
- Small towel. Not every public bathroom has paper towels.
- Coin pouch. You end up with a lot of ¥100 coins.
- Plastic bag for trash, since there are almost no public bins

## Don't bring
- Too many clothes. Uniqlo exists.
