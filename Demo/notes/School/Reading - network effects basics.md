# Reading - network effects basics

Starting point for the paper. Mostly Wikipedia and the NFX manual, to get the vocabulary straight before reading real papers.

- A network effect is when each user gets more value as more people use the product. Phones, fax machines and marketplaces are the textbook examples.
- Direct effects: more users on the same side help each other (messaging).
- Indirect or cross-side effects: more users on one side help the other side (more sellers help buyers). This is the one that matters for marketplaces.
- Negative effects exist too. Congestion, spam, too many sellers chasing the same buyer.

Metcalfe's law says a network's value grows with the square of its users. Nice for a slide. Probably wrong in practice, since most pairs of users never interact. Odlyzko and others argue for n log n. I don't need to settle it, I just shouldn't quote n squared like it's true.

Critical mass: the number of adopters after which adoption keeps going on its own. Before that point everything is fragile and you're pushing.

Bandwagon effect is the psychology version. People join because others joined. Different mechanism, similar curve.
