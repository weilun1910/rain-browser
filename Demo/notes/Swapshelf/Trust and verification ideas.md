# Trust and verification ideas

What makes someone comfortable taking a lamp from, or giving a textbook to, a person they don't know?

Already have:
- yale.edu magic link, so everyone is a real student
- college shown on every listing
- pilot listings only visible inside your own college

Cheap ideas for the pilot:
- No-show strikes. Request something and don't pick it up within 72 hours twice, and you can't request for a week.
- "Picked up" confirmation from both sides before credits move.
- Show how many swaps someone has done. No star ratings. Ratings between classmates get weird fast.

App Review needs these for anything with user-generated content:
- a way to report a listing
- a way to block a user
- a way to filter objectionable stuff
Do the first two properly. For the third, a short word list on titles is enough for now.

Not doing:
- Phone verification. Yale email already does the job.
- Deposits or escrow. That brings money back in, and the whole point of credits is that there isn't any.

Question for Sam: do we show real names or display names? Leaning real first name plus college.
